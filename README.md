Plant Disease Detection Using CNN and ResNet

Project Description

This project investigates the use of deep learning to classify plant diseases from leaf images. A Convolutional Neural Network (CNN) will serve as the baseline model, while ResNet will be evaluated as the main model.

The project will compare CNN and ResNet performance and investigate the effect of data augmentation on ResNet classification performance using a public plant leaf image dataset, such as PlantVillage.

Problem Statement

The objective is to classify plant leaf images into the disease categories represented in the selected dataset and investigate the strengths and limitations of different deep learning approaches.

Research Questions

How does ResNet perform compared with a CNN baseline?

Does data augmentation improve ResNet performance?

Which disease categories are most frequently misclassified?

Planned Experiments

CNN baseline.

ResNet without data augmentation.

ResNet with data augmentation.

Evaluation Metrics

The models will be evaluated using accuracy, precision, recall, F1-score, and confusion matrices. Incorrect predictions will be analyzed to identify model weaknesses and classification errors.

Implementation Workflow

The project will include dataset preparation, preprocessing, training, validation, held-out testing, inference, and failure analysis.

Dataset

The final dataset source, class labels, sample counts, preprocessing procedure, and training/validation/test split will be documented after the dataset is selected and verified.

Reproducibility

Dependencies, environment setup, configuration, hyperparameters, training and evaluation commands, and saved model weights or retraining instructions will be documented as the implementation develops.

Project Structure

The repository structure and file descriptions will be updated as the implementation develops.

Ethics and Limitations

The project will examine dataset limitations, image quality, class imbalance, and generalization to real-world plant images. Predictions are intended for educational and research purposes and should not replace expert agricultural diagnosis.
